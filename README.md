# Web Programming Lab 1–3

This repository contains solutions for the Web Programming exercises in the provided lab sheet.

## Contents

### Lab 1 — Book Information
A home page contains a list of books. Clicking a book opens a separate page showing its information.

### Lab 2 — Product Information
A product-information page displays product name, brand, price and specifications using an HTML table.

### Lab 3A — Cultural Festival Registration
A creative HTML registration form containing:
- Text boxes
- Radio/option buttons
- Check boxes
- Drop-down list
- Text area
- Submit button
- Reset button

### Lab 3B — Book Information Using Frames
A frames-based page with:
- Book list on the left
- Book information on the right
- Links using `target="bookInfo"` so the selected book opens in the right frame

## How to Run

Open each folder's `index.html` file in a browser.

For Lab 3B, use a browser that still supports the legacy HTML `<frameset>` element, or use the files directly as required for the lab demonstration.

## Note

The book covers use Open Library image URLs, so an internet connection is needed for the cover images. The HTML/CSS itself is local.
